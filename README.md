## 这是什么

把课本上的单词和句子，做成孩子愿意主动点开的小游戏。

不是"电子练习册"——每一关都对应一种真实的学习方法（可理解输入、句子挖掘、间隔重复、影子跟读），再用游戏化的奖励把它们包起来。孩子看到的是闯关、星星、收集图鉴；真正发生的是复习、听辨和开口。

**当前进度**：Unit 1 Amazing landmarks、Unit 2 Getting together 已完整可玩（共 10 关 + 单元 Boss），Unit 3–6 待补。

## 关卡设计

| 关卡 | 玩法 | 对应的学习方法 |
|---|---|---|
| 单词关（8 题） | 中英互选、字母卡片 | 间隔重复 + 语块记忆 |
| 听力关（6 题） | 听单词/句子选意思 | 可理解输入 + 听辨训练 |
| 句型关（6 题） | 句子排序、选词填空 | 句子挖掘 + 高频句型 |
| 跟读关（4 题） | 看词句朗读，识别打分 | 影子跟读 + 输出反馈 |
| Boss 关（10 题） | 单元综合测，争三星 | 混合检索 + 即时反馈 |

**解锁规则**：前一关拿到至少 1 星才解锁下一关；四个小关全部通关才开启 Boss 关。Boss 通关即收集该单元的主题纪念品。

## 快速开始

**方式一（最简单）**：双击 `index.html`，用浏览器打开。

**方式二（推荐，功能最全）**：起一个本地服务再访问 `http://localhost:8000`。

```bash
# Python
python -m http.server 8000

# 或 Node
npx serve .
```

> 为什么要起服务？跟读关的语音识别（`SpeechRecognition`）在 `file://` 下会被多数浏览器禁用。用 `localhost` 打开才能真的打分；否则会自动降级成"听示范 + 自评"，不影响正常玩。

## 技术说明

刻意保持了"单文件、零外部资源"的形态：

- **无框架、无构建**：原生 HTML + CSS + JS，所有样式和脚本内联在 `index.html` 里。
- **发音**：`window.speechSynthesis`（系统 TTS），零成本，音色取决于系统装了什么英文语音包。
- **跟读评分**：`SpeechRecognition` 识别结果与目标句做词集相似度比较，≥50% 判过；不支持时自动降级为自评。
- **音效**：`AudioContext` 振荡器实时合成，右上角可一键静音（同时控制朗读）。
- **存档**：`localStorage`，键名 `enq_pep6a_v1`；首页底部"清除学习记录"可重置。
- **插画**：内联 SVG，配合 `aspect-ratio` 精确匹配画幅，避免不同宽高比下的裁切。

## 扩展：新增一个单元

题库集中在 `index.html` 顶部的 `BOOK.units` 数组里，加一个对象即可，玩法无需改动：

```js
{
  id: 'u3', no: 'Unit 3', title: 'Healthy life', cn: '健康生活',
  badge: '健康徽章', color: '#2EC08A', c2: '#16a394',
  words: [ ['headache','头痛'], /* ... 至少 8 个 */ ],
  sentences: [ ['What\'s wrong with you?','你怎么了？'], /* ... 至少 6 句 */ ]
}
```

同时把 `SOON` 里对应的占位项删掉，首页就会自动多出一张可点进去的单元卡片。

> 单词建议 ≥8 个、句子 ≥6 句，否则出题时干扰项会不够。

## 已知限制

- 跟读评分基于「识别文本与目标句的词重合度」，不是音素级发音评测，只能判断"读没读对内容"，判断不了口音细节。
- 朗读音色依赖操作系统语音包，没有安装英文语音包的机器可能读得比较机械。
- 目前只有 2 个单元共 10 关，Unit 3–6 尚未开放。
