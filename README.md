## 这是什么

把课本上的单词和句子，做成孩子愿意主动点开的小游戏。

不是"电子练习册"——每一关都对应一种真实的学习方法（可理解输入、句子挖掘、间隔重复、影子跟读、规则归纳），再用游戏化的奖励把它们包起来。孩子看到的是闯关、星星、收集图鉴；真正发生的是复习、听辨、拼写和开口。

**当前进度**

| 版本 | 文件 | 教材 | 单元 | 关卡 |
|---|---|---|---|---|
| 七年级上册 | [`grade7.html`](grade7.html) | 人教版（2024 修订） | Starter + Unit 1–7，**8 个单元全部可玩** | **7 关 / 单元**，共 56 关 |
| 六年级上册 | [`index.html`](index.html) | 人教版（2024 修订） | Unit 1–2 可玩，Unit 3–6 待补 | 5 关 / 单元 |

两册各自独立存档、互不影响，可以同时玩。

## 关卡设计（七年级上册 · 7 关）

| 关卡 | 玩法 | 题量 | 对应的学习方法 |
|---|---|---|---|
| 单词关 | 中英互选 | 8 | 间隔重复 + 语块记忆 |
| 拼写关 | 看中文，点字母块拼出单词 | 8 | 提取练习（production）+ 拼写巩固 |
| 听力关 | 听单词 / 句子选意思 | 6 | 可理解输入 + 听辨训练 |
| 句型关 | 句子排序、选词填空 | 6 | 句子挖掘 + 高频句型 |
| 语法关 | 语法选择，附语法点与错因 | 6 | 规则归纳 + 即时纠错 |
| 跟读关 | 看词句朗读，识别打分 | 4 | 影子跟读 + 输出反馈 |
| Boss 关 | 七种题型混合测，争三星 | 12 | 混合检索 + 即时反馈 |

**解锁规则**：前一关拿到至少 1 星才解锁下一关；六个小关全部通关才开启 Boss 关。Boss 通关即收集该单元的主题纪念品。

**难度设计上的两个细节**

- 拼写关第一次拼错只提示、不清空，给第二次机会——避免一个手滑就断掉连对，但两次都错仍算错题入队。
- 句子填空优先挖本单元的课标词，而不是随便挖一个虚词，保证填空题真的在复现目标词汇。

六年级上册沿用 5 关结构（单词 → 听力 → 句型 → 跟读 → Boss），题量与题型见 `index.html` 顶部 `BOOK` 与 `LEVEL_DEFS`。

## 城堡保卫战（塔防模式）

首页"城堡保卫战"入口进入。七上目前有第 1 战场（Unit 1，4 波）。

**玩法**：错误从右侧沿路冲向左侧城堡，你在路边建塔拦截。每只怪身上写着一个真实的典型错误——`goed`、`two book`、`be`——答对的瞬间它变成正确形式并消散。

| 设计 | 说明 |
|---|---|
| **敌人 = 一个具体错误** | 拼写怪的错法是把相邻字母交换（`friend → freind`），正好是学生最常犯的那类 |
| **类型必须匹配** | 只有对应类型的塔打得动对应类型的怪，所以孩子得先认出"这是哪一类错误" |
| **布防即判断** | 每波开打前会预告下一波构成，据此决定建什么塔 |
| **金币不宽裕** | 初始 150 金，四座塔全建要 255 金，必须有取舍；但拆塔返还一半，改主意不必硬扛 |
| **战斗不停** | 敌人一直在走，只有被塔锁定时会减速。答完一题自动接下一题，没有"下一题"按钮 |

四种塔对应四种题型：词汇塔 / 拼写塔 / 听力塔 / 语法塔。射程略有差异（42–50），拼写题的敌人会被拖得更慢——因为要点一串字母块，比选择题费时。

画面是古罗马要塞风格（参照《王国保卫战》）：草地、铺石路、带拱门和铁闸的罗马城墙、柏树与断柱。四种塔给了四个完全不同的剪影（方塔 / 圆穹 / 尖顶哨塔 / 神殿），升到 Lv2 挂小旗、Lv3 加金线——等级靠外观长出来，不靠数字。

九格塔位、随时可拆可补、锁定环标出正在被瞄准的敌人、点塔显示射程圈。

> 为什么没做横版动作（冒险岛、造梦西游那种）？因为动作操作和语言加工抢同一份注意力，孩子容易变成"操作高手、答题机器"。塔防的操作负荷接近零，认知资源全留给题目，而且它的"选择"能直接承载知识点的分类判断。完整论证见 [docs/DESIGN-TOWER-DEFENSE.md](docs/DESIGN-TOWER-DEFENSE.md)。

## 七年级上册单元与语法分布

| 单元 | 主题 | 核心语法 |
|---|---|---|
| Starter | Hello & Welcome（起步营） | be 动词、a/an、this/that/these/those、方位介词、名词复数 |
| Unit 1 | You and Me | be 动词一般现在时、人称代词与物主代词、would like to do |
| Unit 2 | We're Family! | 实义动词一般现在时（含三单）、名词所有格 's、Whose |
| Unit 3 | My School | There be 句型与就近原则、方位介词、have 与 there be 之别 |
| Unit 4 | My Favourite Subject | and / but / because、What/Why/Who/When 特殊疑问句、时间介词 |
| Unit 5 | Fun Clubs | 情态动词 can、play + 球类/乐器、be good at |
| Unit 6 | A Day in the Life | 三单变化规则、do/does 提问、at/on/in 时间介词 |
| Unit 7 | Happy Birthday! | 序数词、日期表达、How old / How many、不可数名词 |

> Starter Unit 1–3 每单元词汇量只有 8–10 个，各自撑不起 7 关，因此合并为一个"起步营"单元，词汇覆盖问候、教室物品、方位与农场动物。

## 快速开始

**方式一（最简单）**：双击 `grade7.html` 或 `index.html`，用浏览器打开。

**方式二（推荐，功能最全）**：起一个本地服务再访问。

```bash
python -m http.server 8000
# 七年级上册：http://localhost:8000/grade7.html
# 六年级上册：http://localhost:8000/
```

> 为什么要起服务？跟读关的语音识别（`SpeechRecognition`）在 `file://` 下会被多数浏览器禁用。用 `localhost` 打开才能真的打分；否则会自动降级成"听示范 + 自评"，不影响正常玩。

## 技术说明

刻意保持了"单文件、零外部资源"的形态：

- **无框架、无构建**：原生 HTML + CSS + JS，所有样式和脚本内联在文件里。
- **题库数据驱动**：单元、词汇、句型、语法题全部集中在 `BOOK.units`，玩法代码不含任何具体词条。
- **发音**：`window.speechSynthesis`（系统 TTS），零成本，音色取决于系统装了什么英文语音包。
- **跟读评分**：`SpeechRecognition` 识别结果与目标句做词集相似度比较，≥50% 判过；不支持时自动降级为自评。
- **音效**：`AudioContext` 振荡器实时合成，右上角可一键静音（同时控制朗读）。
- **存档**：`localStorage`，七上键名 `enq_pep7a_v1`，六上键名 `enq_pep6a_v1`；首页底部"清除学习记录"可重置。
- **插画**：内联 SVG，配合 `aspect-ratio` 精确匹配画幅，避免不同宽高比下的裁切。
- **安全基线**：通过 CSP `default-src 'none'` 从机制上禁止外部脚本、外链样式、iframe 与任何网络请求；设置 `referrer: no-referrer`。即使将来代码被改动，外部资源也加载不进来。

## 隐私说明

这一项对家长比功能表更重要，所以单独写清楚：

| 问题 | 答案 |
|---|---|
| 有没有服务器？ | 没有。它是纯静态的单个 HTML 文件，不上传任何数据 |
| 收集个人信息吗？ | 不收集。不需要注册、不填姓名、不填班级，没有任何表单 |
| 学习记录存在哪？ | 只存在你这台设备的浏览器 `localStorage` 里，清缓存或点"清除学习记录"即消失 |
| 有统计和广告吗？ | 没有。无 Google Analytics、无埋点、无广告 SDK、无第三方字体 |
| 联网吗？ | 页面本身零外部请求，断网可玩 |
| **麦克风呢？** | 只有跟读关会用到，且是**你主动点按钮**才触发。首次使用前会弹说明，可以直接拒绝并改用自评 |

**关于录音的唯一一处例外，需要如实说明**：跟读关的语音识别调用浏览器自带能力（`SpeechRecognition`）。Chrome 会把这段音频发送到 Google 的服务器完成识别，Edge 走微软，Safari 走苹果。**本游戏自身不接收、不上传、也不保存任何录音**，打分只用识别返回的文字；但这个识别过程不受本项目控制。介意的话可以在弹窗里选择"不用麦克风"，跟读关会降级成"听示范 + 自己判断"，其他关卡完全不受影响。

## 发布前检查

改动后要公开推送时，先跑一遍检查脚本：

```bash
bash scripts/preflight.sh
```

它会逐个检查仓库里的所有 HTML 页面：硬编码密钥、本机路径、个人邮箱手机号、外部请求、`eval`、麦克风说明，外加仓库卫生与提交邮箱，返回非 0 即表示不要发布。CI 里同一脚本会自动执行（`pages.yml` 的 `preflight` job），不通过就不会部署。

题库自检（不依赖浏览器，校验每个单元词句数量、选项去重、答案是否在选项里、插画标签是否闭合）：

```bash
node scripts/selftest-grade7.js
```

塔防模式冒烟（用无头浏览器自动建满塔、拆一座验证返款、逐题答对跑完整个战场，断言能通关且**答题期间敌人位置一直在变**）：

```bash
python scripts/smoke-td.py
```

塔防节奏压力测试（按真实 60fps 推进，模拟每道题思考 2–6 秒，另跑一组"只给初始金币、按需建塔"的经济检查）：

```bash
python scripts/pace-td.py
```

答题闯关全量回归（8 单元 × 7 关共 400 题，断言每关都能答完并拿三星）：

```bash
python scripts/smoke-levels.py
```

完整清单（含脚本查不出、必须人工判断的项）见 [docs/PRE-RELEASE-CHECKLIST.md](docs/PRE-RELEASE-CHECKLIST.md)。

## 扩展：新增一个单元（七年级版）

题库集中在 `grade7.html` 顶部的 `BOOK.units` 数组里，加一个对象即可，玩法无需改动：

```js
{
  id: 'u8', no: 'Unit 8', title: 'New topic', cn: '新主题',
  badge: '纪念品名', color: '#4F6BED', c2: '#7C5CFF',
  words:     [ ['word','词义'], /* ... 建议 ≥16 个 */ ],
  sentences: [ ['English sentence.','中文意思'], /* ... 建议 ≥8 句 */ ],
  grammar:   [ ['She ___ a sister.', 'has', ['have','is','are'], '语法点', '一句话解析'], /* ... 建议 ≥6 道 */ ]
}
```

> 数量下限不是凑数：拼写关需要 8 个词、单词关需要 8 个词且干扰项要不重复、语法关要抽 6 道，少于这些量出题会重复或选项不够。

## 已知限制

- 跟读评分基于「识别文本与目标句的词重合度」，不是音素级发音评测，只能判断"读没读对内容"，判断不了口音细节。
- 拼写关用字母块点击而非键盘输入，长单词的字母块会比较多（最多 12 块）。
- 语法关是"单点规则"的选择题，覆盖不到需要多句判断的复杂语境。
- 朗读音色依赖操作系统语音包，没有安装英文语音包的机器可能读得比较机械。
- 六年级上册目前只有 2 个单元共 10 关。
- 塔防模式目前只有 Unit 1 一个战场；塔的等级只影响射程与等级徽章，没有伤害数值差异（怪血量固定为 1，答对即消灭）。
- 塔防的敌人走完全程才会漏怪，一场战斗约 1–1.5 分钟；漏怪时孩子只能看着，没有"紧急补塔救场"的机制。
