## 1. 项目定位

| 项目 | 内容 |
|---|---|
| 名称 | 英语闯关（暂定） |
| 形态 | 小学英语课内同步学习游戏 |
| 目标用户 | 六年级学生（11–12 岁），个人自用，后续扩展多人 |
| 核心目标 | 用游戏化 + 学习科学，帮孩子同步掌握课本词汇、句型、听力、口语，实现**课内提分** |
| 差异点 | 市面上多为通用 AI 聊天陪练；本产品**严格同步教材单元**，且把学习法内建成游戏机制 |
| 成本约束 | 单文件网页、零服务器、可离线，先跑通再扩展 |

## 2. 设计原则

1. **课内同步优先**：内容严格对齐教材单元，不做脱离课本的泛化内容。
2. **学习科学驱动**：可理解输入、句子挖掘、间隔重复（SRS）、输出反馈、自适应 i+1。
3. **奖励绑定学习**：所有奖励来自真实学习行为（含复习错题），杜绝"刷简单关薅奖励"。
4. **低成本可扩展**：题库与玩法解耦；先单机，再上云多人。
5. **孩子视角**：大按钮、即时反馈、短关卡、强收集欲。

## 4. 平台与技术方案

| 层 | 选型 | 说明 |
|---|---|---|
| 形态 | 单文件 HTML（HTML + CSS + JS 内联） | 双击即玩，零构建、零依赖 |
| 存储 | localStorage | 进度、星星、金币、错题、收集 |
| 发音 | Web Speech API `speechSynthesis` | 免费 TTS 读单词和句子，出听力题 |
| 跟读 | Web Speech API `SpeechRecognition` | 支持则打分；不支持自动降级为"听示范 + 自评" |
| 题库 | 内联 JSON（结构化） | 后续可由 AI 出题引擎生成 |
| 发布 | 需要时用在线发布生成链接 | 零服务器起步 |

> 说明：`SpeechRecognition` 在 `file://` 下部分浏览器不可用，因此跟读关设计了自评降级方案，保证任何环境可玩。

### 4.1 视觉与交互层

目标：**看起来像一个能玩的手游，而不是一份电子练习册**。全部用 CSS + 内联 SVG 实现，不引用任何外部图片/字体，保证离线可用。

| 元素 | 做法 |
|---|---|
| 吉祥物 | 内联 SVG 猫头鹰"小闯"，眨眼 + 上下浮动动画，出现在首页、单元页、结算页 |
| 单元插画 | 每单元一张 200×120 的 SVG 场景（地标山峦/节日灯笼/健康/钱包/火箭/地球），锁定态自动灰度 |
| 关卡地图 | 横向 5 节点路径图：已通关显示星级、当前关呼吸光环、未解锁显示锁图标 |
| 动效 | 卡片入场、答错抖动、答对连对提示、三星弹跳、通关撒花（DOM 粒子） |
| 音效 | WebAudio 实时合成（答对/答错/点击/通关），无需音频文件，右上角一键静音 |
| 视觉体系 | 渐变 + 柔和投影 + 光晕背景，主色蓝紫、奖励金，中文圆润无衬线 |
| 响应式 | ≤560px 单列布局，关卡节点/字号自适应 |

```
 └─ 收集图鉴
```

## 6. 玩法与关卡设计

每个单元排 5 关，每关一种玩法：

| 关卡 | 题型 | 说明 | 题量 | 对应学习法 |
|---|---|---|---|---|
| 单词关 | 中英互选 | 中文选英文 / 英文选中文 | 8 | 间隔重复 + 语块 |
| 听力关 | 听音辨义 | 播放 TTS，选单词/句子的意思 | 6 | 可理解输入 + 听辨 |
| 句型关 | 排序 + 选词填空 | 打乱单词重排成句 / 句子挖空选词 | 6 | 句子挖掘 + 高频句型 |
| 跟读关 | 朗读评分 | 听示范 → 录音 → 相似度打分（可降级自评） | 4 | Shadowing + 输出 |
| Boss 关 | 混合题 | 综合抽题，全对争三星 | 10 | 输出 + 即时反馈 |

**解锁规则**
- 第 1 关默认解锁；第 n 关需第 n−1 关至少 1 星。
- Boss 关需前 4 关全部通关。
- U1、U2 均可直接进入（方便跟随课堂进度）。

**星级规则**（正确率）
- ≥ 90% → 3 星｜≥ 75% → 2 星｜≥ 60% → 1 星（通关）｜< 60% → 0 星（重来）

## 7. 奖励机制

三段闭环：**怎么赚 → 赚什么 → 花在哪**

| 怎么赚（来源） | 赚什么（货币） | 花在哪（用途） |
|---|---|---|
| 闯关得分 | 星星（1–3） | 升级等级 |
| 每日打卡 | 金币 | 兑换装扮 / 头像（后续） |
| 复习错题 | 经验 XP | 主题收集图鉴 |
| Boss 通关 | 成就徽章 | 排行榜（多人版） |

**数值（MVP）**
- 金币 = 星星 × 20 + 答对数 × 5 + 首次通关 30
- 经验 = 答对数 × 10 + 星星 × 15
- 等级 = 1 + ⌊经验 / 120⌋
- 错题复习：每答对 +8 金币、+6 经验

**防刷原则**
- 奖励只来自"首次通关 / 刷新星数 / 复习"。
- 复习答对才移除错题，答错继续留在队列。

**主题收集（结合新教材）**
- 通关某单元 Boss → 解锁该单元主题纪念品（如「地标明信片」「节日纪念章」）。
- 集齐图鉴 = 学完整册，且天然是给家长的"学习成果展示"。

## 8. 数据结构

### 8.1 题库（内联）
```js
{
  id: 'u1',
  no: 'Unit 1',
  title: 'Amazing landmarks',
  cn: '神奇的地标',
  badge: '地标明信片',
  color: '#4F6BED',
  words: [ ['landmark','地标'], ['amazing','令人惊奇的'], ... ],
  sentences: [ ['How was your weekend?','你周末过得怎么样？'], ... ]
}
```

### 8.2 存档（localStorage `enq_pep6a_v1`）
```js
{
  coins: 0,             // 金币
  xp: 0,                // 经验
  streak: 0,            // 连续学习天数
  lastDate: null,       // 最近学习日期
  progress: {           // 每关星星：'u1-0': 3
    'u1-0': 3
  },
  collect: ['u1'],      // 已收集单元
  wrong: [],            // 错题队列（题目对象）
  sound: true
}
```

## 12. MVP 验收标准

- [x] 打开 HTML 即可玩，无需联网。
- [x] 能选单元、进入 5 个关卡，关卡按规则解锁。
- [x] 4 种题型 + Boss 关正常工作，答题有即时反馈。
- [x] 听力题能自动/手动播放英文发音。
- [x] 跟读关在支持语音识别的浏览器可打分，不支持时自动降级自评。
- [x] 结算正确计算星星、金币、经验，并持久化。
- [x] 错题进入复习队列，复习答对后移除。
- [x] 通关 Boss 解锁主题收集品，图鉴可见。
- [x] 刷新页面后进度不丢失。
